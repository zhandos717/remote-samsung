# TV Remote

PWA-пульт для Samsung Tizen TV по локальной сети (websocket, порт 8002).
Откройте страницу, введите IP телевизора, нажмите «Подключить».

Инструкция и ограничения: на ТВ включите «Первый раз» в Диспетчер подключения устройств,
примите сертификат https://<IP>:8002/api/v2/ один раз в браузере.
